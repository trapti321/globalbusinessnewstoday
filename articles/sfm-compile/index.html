SFM Compile Guide: How to Compile Models for Source Filmmaker With Studiomdl and Crowbar

How to compile models for Source Filmmaker: QC files, studiomdl, Crowbar, output folders and common errors, plus why to avoid fake "SFMCompile" downloads.

GBNT Newsroom • Published Nov 11, 2026 • 8 min read
Share

"SFM compile" means turning a 3D model's source files into the .mdl format that Valve's Source Filmmaker can load. You do it with Valve's own compiler, studiomdl.exe, which ships inside Source Filmmaker, usually through the free Crowbar tool. There is no official program called "SFM Compile" or "SFMCompile.exe", so be wary of sites offering one as a download. This guide covers the tools, the QC script, the steps and the most common errors, checked against Valve's developer documentation on November 11, 2026.

SFM compile, the short answer:

  • What you need: source files (SMD or DMX), a QC script, Source Filmmaker's studiomdl.exe and, optionally, Crowbar.
  • Where studiomdl is: in your SFM install, typically ...\steamapps\common\SourceFilmmaker\game\bin\studiomdl.exe.
  • Where models go: the usermod folder, under models and materials.
  • Easiest route: Crowbar 0.74, a free compile and decompile tool.
  • Safety: download tools only from Steam or Crowbar's official GitHub page.

What Is Source Filmmaker?

Source Filmmaker (SFM) is Valve's free animation tool, built on the Source engine and used to make movies with game assets. According to its Steam page, it was released on July 10, 2012, and is "available for free as a public beta". Its last announced update on Steam was version 0.9.8.15, in January 2015. Valve's newer Source 2 Filmmaker is available only inside the workshop tools of games such as Counter-Strike 2 and Dota 2.

What Does "Compiling" a Model Mean?

Valve's developer wiki explains that "Models need to be compiled before they can be used in a game" and that a compile has three parts:

  1. Source files: the model's mesh, skeleton and animations, exported from Blender or another 3D program as SMD or DMX files (plus VTA files for flex animation).
  2. A QC file: a plain-text script that tells the compiler what to build.
  3. StudioMDL: Valve's command-line compiler, which reads the QC and writes the finished model.

According to the StudioMDL documentation, the output is a set of files: the .mdl itself, .vvd vertex data, .vtx files for rendering, and a .phy file if the model has collision.

Step 1: Write a QC File

A minimal QC for a static prop, based on the example in Valve's wiki, looks like this:

$modelname "props\myfirstmodel.mdl"
$body mybody "myfirstmodel-ref.smd"
$surfaceprop combine_metal
$cdmaterials "models/props"
$sequence idle "myfirstmodel-ref"
$collisionmodel "myfirstmodel-phys" { $concave }
CommandWhat it does
$modelnameRequired. Output path, relative to the game's models folder.
$bodyThe reference mesh (SMD or DMX).
$cdmaterialsFolder the game searches for textures, relative to materials. Subfolders are not searched.
$sequenceAn animation. Valve notes that "All models must have at least one $sequence, even if they aren't actually animated!"
$collisionmodelA static collision mesh. Animated ragdolls use $collisionjoints instead.

The full list is in Valve's QC commands reference.

Step 2: Compile With Crowbar (Recommended)

Crowbar, by the developer ZeqMacaw, is a free tool that puts a graphical interface on studiomdl. It can "Compile and decompile models individually or from an entire folder", and it supports Source Filmmaker. The latest release is version 0.74, published on GitHub on February 20, 2023.

  1. Download Crowbar from its official GitHub releases page (or its Steam group) and unzip it.
  2. In Crowbar's game setup, add Source Filmmaker and point it at your SFM install, so it finds studiomdl.exe and gameinfo.txt.
  3. Open the Compile tab and select your QC file.
  4. Choose the output folder (your SFM usermod folder is the usual choice) and click Compile.
  5. Read the log. A successful compile ends with the list of written files.

Crowbar also creates missing output folders automatically, which avoids a common studiomdl error (see below).

Step 2 (Alternative): Compile From the Command Line

Valve documents the usage as studiomdl [options] <path\QC>. For SFM, a typical command is:

"C:\Program Files (x86)\Steam\steamapps\common\SourceFilmmaker\game\bin\studiomdl.exe" -nop4 -game "C:\Program Files (x86)\Steam\steamapps\common\SourceFilmmaker\game\usermod" "C:\models\myfirstmodel.qc"

The -game option sets where compiled files are written, and -nop4 disables Valve's internal Perforce integration, which Valve's wiki says "you should use". The SFM-specific folder paths come from community advice on the Source Filmmaker Steam forums; adjust them to your own Steam library location.

Step 3: Add Textures (VMT and VTF)

Source models use VTF files for images and VMT files to describe materials. Place them under usermod\materials\, in the folder named in your $cdmaterials line. VTFEdit is the classic converter, though Valve's wiki marks it as abandoned and points to maintained forks such as VTFEdit Reloaded.

Step 4: Load the Model in SFM

Open Source Filmmaker, create or open a session, and add the model from the model browser. If you compiled to usermod, it appears under the path set in $modelname.

Common SFM Compile Errors and Fixes

ErrorFix
"Error opening <model>! (Check for write enable)"Studiomdl will not create folders that do not exist. Create them, or use Crowbar.
EXCEPTION_ACCESS_VIOLATIONValve suggests compiling with the Half-Life Model Viewer (HLMV) running.
"Bad collision model, check your smoothing groups"Fix the smoothing groups on your collision mesh.
"Model has 2-dimensional geometry"Put all faces of the collision mesh in smoothing group 1.
"Bounding box out of range"The collision model is larger than 16,384 units; split the model.
Purple and black checkerboard texture in SFMMissing material: check $cdmaterials and the VMT/VTF location.

The fixes above for the first five errors come from Valve's wiki; the last is a common community fix.

A Warning About "SFM Compile" Websites

Searches for "sfm compile" and "sfmcompile" return many content-farm pages and look-alike domains. Some describe "SFM Compile" as a tool you should download as a ZIP or EXE. No official tool by that name exists. At least one similarly named domain hosts adult content. Running executables from unknown sites is a common way to install malware, so stick to:

  • Source Filmmaker itself, from Steam (studiomdl.exe is included).
  • Crowbar, from its GitHub releases page or Steam group.
  • Valve's developer wiki for documentation.

SFM Compile FAQs

What is SFM compile?

Converting a model's source files and QC script into a .mdl model that Source Filmmaker can use, using Valve's studiomdl compiler.

Is there an official "SFMCompile" tool?

No. Use studiomdl.exe, which comes with SFM, or the free Crowbar interface.

Where do compiled SFM models go?

Usually in SFM's game\usermod\models folder, with textures in game\usermod\materials.

Can Crowbar decompile SFM models?

Yes. Crowbar can decompile .mdl files back into QC and SMD files, which is useful for editing. Respect the original creator's permissions.

Is Source Filmmaker still free?

Yes. It remains a free public beta on Steam.
